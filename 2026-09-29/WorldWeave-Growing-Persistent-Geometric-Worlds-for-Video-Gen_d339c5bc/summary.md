# 论文速读：WorldWeave: Growing Persistent Geometric Worlds for Video Generation

## 一句话总结
WorldWeave 提出了一种将世界状态维护与视觉渲染解耦的框架，通过扩散模型地形扩展、智能体引导的场景规划与确定性几何编译，构建可扩展的显式3D持久世界，在无预设边界条件下实现跨视角回溯的几何一致性视频生成。

## 研究问题与动机
1. 现有世界模型缺乏显式、持久的结构记忆，在持续场景扩展和跨视角回溯时难以保持世界结构一致性。
2. 当前方法依赖图像/视频隐式传递世界信息，需要生成器重新推断历史内容，局部视觉连贯性无法保证持久结构一致性。
3. 场景扩展要求新区域无缝衔接现有地形、道路和水系，同时不改变已确立的结构；重复访问需要稳定空间结构而非每次重建几何关系。
4. 视觉生成与几何结构维护的耦合限制了可扩展世界的持续探索能力，需要分离结构记忆与观察生成。

## 核心贡献（创新点）
1. **持久性结构记忆框架**：首次将世界状态维护与视觉渲染完全解耦，支持增量构建和跨轨迹/回溯的共享几何查询；与现有方法依赖隐式帧缓存或几何记忆本质不同，采用经验证的场景构建维护显式记忆。
2. **持续度量地形扩展**：结合扩散图像扩展、多尺度高程残差编码和新侧边界约束生成完整度量地形块并连续拼接；相较依赖固定网格或重叠查询的方法，本文采用固定顺序扩展并结合邻居约束与边界连续性保证。
3. **智能体引导的场景构建**：层次化语义规划、确定性几何编译、受限局部修订与验证提交的结合；相比纯程序化或纯学习方法，在继承邻居接口基础上实现结构化规划与几何约束双重保证。

## 方法详解
WorldWeave 框架由五个核心组件构成：

**1. 持久性结构记忆**
世界状态在共享度量坐标系中维护，表示为 $M_k = (\mathcal{T}_k, \mathcal{P}_k, \mathcal{I}_k, \bar{\mathcal{T}}_k)$，其中 $\mathcal{T}_k$ 存储高程和边界导数，$\mathcal{P}_k$ 存储区域组织和对象关系，$\mathcal{I}_k$ 存储资产网格引用和变换，$\bar{\mathcal{T}}_k$ 存储暴露的边界接口。每次扩展请求读取已提交状态并独立构建候选 $\Delta M_q$，仅验证通过的添加才会原子化创建新版本 $M_{k+1} = M_k \oplus \Delta M_q$。

**2. 持续度量地形扩展**
- 地形块参数：512×512 高程采样（0.5m 间距），对应 256×256m 覆盖范围
- 多尺度残差编码：从有效邻居边界带拟合参考平面 $b_q(x,y)$，残差 $r_q = h_q - b_q$，通过三个单调通道编码 $c_{q,j} = \frac{1}{2} + \frac{1}{2}\tanh(r_q/s_j)$，尺度 $(s_1,s_2,s_3)=(8,32,128)\text{m}$
- 条件扩散模型：基于 Qwen-Image-Edit-2509 使用 rank-32 LoRA 适配，冻结 VAE 和文本编码器
- 边界约束损失：$w_q(x) = 1 + \frac{3}{2}[1+\cos(\pi\min\{d_q(x)/a,1\})]$，其中 $a=16\text{m}$，在目标损失格点上加权扩散损失 $\mathcal{L}_q$
- 地形拼接：新侧高度修正 $\delta_q$ 在支撑域内满足 $h_q^+|_{\Gamma_e} = g_e$ 和 $\partial_{n_e}h_q^+|_{\Gamma_e} = v_e$；连接单元使用双三次 Hermite 补丁继承边界高度和导数

**3. 分层场景规划与编译**
- 从接受的高程场确定性地提取坡度、局部起伏、排水和可建区域证据
- 智能体结合用户意图 $u$、继承接口 $\bar{\mathcal{T}}_k$ 和资产能力分配区域角色（如居住区、林地、河流走廊）
- 区域求解器将语义分配转为空间范围；街区规划指定角色、邻接和访问需求
- 资产关系计划确定主次服务角色、共享空间和朝向
- 确定性编译器将计划转为稳定实例身份和度量变换，接受条件为 $g_r(\mathcal{T}_q, h_q^+; M_k) = 1$（满足目录支持的几何关系）

**4. 受限修订与验证提交**
- 区域审查检查继承连接、覆盖范围和地形可行性
- 编译后程序检查评估支撑、碰撞和连通性，配合匹配视角的 GPU 几何和深度预览
- 修订迭代：$\pi_q^{(t+1)} = \text{Edit}(\pi_q^{(t)}, \delta\pi_q^{(t)})$，$\Delta M_q^{(t+1)} = \text{Compile}(\pi_q^{(t+1)}; M_k)$，$t < K$
- 原子提交：$M_{k+1} = M_k \oplus \Delta M_q$，保留 $\Omega_k$ 中的已有记录

**5. 只读查询视频生成**
- 相机轨迹 $C_{1:T}$ 查询已提交版本 $M_k$，返回度量深度序列 $D_{1:T} = Q(M_k, C_{1:T})$
- 视频生成 $V_{1:T} = F(A_F(D_{1:T}), s_F)$，RGB 不写回世界状态
- 空间对应关系：$\tilde{x}_t(X) \sim K_t R_t^\top(X - c_t)$，同一表面点在不同视角下投影满足相同几何约束

## 实验与结果
- **数据集**：120 个任务，涵盖前向探索、视角变化和遮挡/离屏返回；地形起伏、植被生物群系（森林/草原）、聚落布局（村庄/城镇）多样；视频长度 15 秒 @ 12fps
- **基线**：6 个开源世界模型（SANA-WM, Zing, SolarWM-5B, AlayaWorld, Alaya-EVOKE-Turbo, JoyAI-Echo-1.5）和 4 个视频模型（Seedance 2.0, Wan3.0, Kling 3.0, MiniMax-H3）
- **指标**：IQ、AQ（VBench 视觉质量）；SMC、Cam（记忆与相机控制）；MN-MS、MC-GeCo、MC-MEt3R、MC-GeoCon（运动校准后的结构一致性）
- **主要结果**：WorldWeave IQ 排名第五（0.781），AQ 排名第二（0.704）；在 MN-MS、MC-GeCo、SMC、Cam、MC-MEt3R、MC-GeoCon 六项指标均居首位
- **最强提升**：相对 MiniMax-H3，SMC 提升 **+426.7%**（0.438→2.30），Cam 提升 **+42.2%**（50.8→72.3），MC-GeoCon 误差减少 **32.2%**
- **几何一致性**：MC-GeCo 最低 0.0573，MC-MEt3R 最低 0.122
- **消融**：残差编码使 VAE 往返 RMSE 从 2.182m 降至 0.136m；Canvas 条件使边界高度间隙降低 65.4–76.1%；导数继承+斜率收缩使高度和斜率残差降至 $<10^{-9}$
- **用户研究**：WorldWeave 在相机（4.57）、物体（4.73）、结构/纹理一致性（4.52）均排名第一，较 Echo-WM 分别提升 0.65、1.31、1.20 分

## 相关工作脉络
1. **Video World Models（Echo-WM, Zing, SolarWM-5B, SANA-WM）**：这些方法关注视觉生成与相机控制，但缺乏显式持久结构记忆；WorldWeave 的核心差异在于通过验证的场景构建维护显式记忆，而非依赖帧缓存或因果缓存。
2. **Structural Memory Methods（WorldMem, GEN3C, Alaya-EVOKE-Turbo, AlayaWorld）**：使用3D缓存或几何记忆间接维持结构；WorldWeave 采用独立度量坐标系显式存储地形、资产和关系，视频生成作为只读查询而非写回。
3. **Persistent 3D Worlds（InfiniCube, XCube, LT3SD, One2Scene）**：使用稀疏体素或潜层树；WorldWeave 的核心差异在于支持固定顺序扩展、边界接口继承，以及确定性编译与受限修订的结合。
4. **Agent-Guided Construction（3D-GPT, SceneCraft, Holodeck, WorldClaw, Code2Worlds）**：通过语言驱动或视觉引导进行场景构建；WorldWeave 的特点是在继承邻居接口的约束下进行层次化语义规划和确定性几何编译。
5. **Terrain Generation（InfiniteDiffusion, TerraFusion, MESA）**：支持重叠查询或联合生成；WorldWeave 采用固定顺序扩展，通过新侧高程和导数约束实现连续拼接，而非随机访问。
6. **Geometric Consistency（WorldStereo, Geometry-as-context）**：通过3D几何对应关系连接视图；WorldWeave 的核心创新是提供可寻址的显式几何世界，视频生成只读查询深度序列而非直接重建。

## 局限性与未来方向
1. 当前仅支持静态几何，深度提供引导而非硬性渲染约束，无法处理动态交互。
2. 长期外观记忆机制尚未完善，长时间跨度下的外观一致性有待解决。
3. 自适应空间细节机制未充分展开，更大规模世界的生成能力有限。
4. 未来工作方向：动态交互建模、长视野外观记忆、自适应空间细节、扩展至更大规模世界。

## 研究启发与可借鉴点
1. **显式结构记忆与视觉生成的解耦设计**：将世界状态维护独立于视频生成窗口，这一架构思想可迁移到需要长期一致性的生成任务（如交互式故事生成、游戏世界构建）中。
2. **多尺度残差编码策略**：通过参考平面减去背景趋势，再用多尺度单调通道编码局部残差，可有效解决图像模型动态范围与度量数据尺度不匹配的问题，可借鉴于遥感、医疗影像等科学数据的图像化表示。
3. **边界约束加权损失函数**：使用距离边界的归一化余弦加权强化边界区域连续性，这一设计对图像扩展、风格迁移、分割掩码融合等任务中的边界处理具有参考价值。
4. **验证-提交原子操作模式**：候选状态独立构建、验证通过后原子更新，这一模式可应用于需要版本控制和事务安全性的任何增量式构建系统。
5. **只读查询架构**：视频生成仅读取世界状态而不写回，避免生成过程中的状态污染，可推广至多模态生成系统的一致性维护。

## 关键术语表
- **Persistent Structural Memory**：持久性结构记忆——在共享度量坐标系中独立维护的显式3D世界状态，包含地形、资产和关系，独立于视频生成窗口。
- **Continual Metric Terrain Expansion**：持续度量地形扩展——基于扩散图像扩展，结合多尺度高程残差编码与新侧边界约束，生成连续连接的地形块。
- **Hierarchical Semantic Planning**：层次化语义规划——智能体结合用户意图、地形证据和继承接口，从区域角色到街区细节的分层场景组织。
- **Deterministic Geometry Compilation**：确定性几何编译——将场景计划转换为稳定实例身份和度量变换的过程，满足几何关系谓词。
- **Bounded Revision**：受限修订——基于程序检查和匹配视角预览的有界迭代修改，最多 K 次修订后提交或拒绝候选。
- **Read-only Query**：只读查询——相机轨迹查询已提交世界版本获取深度序列，视频生成结果不写回世界状态。
- **Structural Memory Consistency (SMC)**：结构记忆一致性——评估目标消失后重新出现时身份、结构和邻居关系的保持程度。
- **Camera Compliance (Cam)**：相机合规性——评估生成的视频是否遵循请求的相机运动、转折和观察顺序。
