# 论文速读：V-GYM-ENHANCING-AGENTIC-VISUAL-REASONING-VIA-SKILL-DATA-CO-E

## 一句话总结
V-Gym 提出了一种自主的代理式视觉推理自我改进框架，以执行轨迹为共享证据源，协同迭代精炼程序化技能库与多模态练习数据集，实现“技能指导靶向数据生成、高质量数据反哺技能持续更新”的闭环自提升。

## 研究问题与动机
1. **经验复用不可靠**：有限执行轨迹易提炼出泛化性差或适用边界模糊的技能，静态技能库难以随任务复杂度提升而自适应打磨。
2. **静态数据集的适配缺陷**：固定练习集缺乏针对技能演进痛点的多样化与靶向性，无法动态支撑持续的技能修正与边界测试。
3. **多模态生成的难度控制难**：自主生成数据时，需在引入多样性的同时保留核心推理挑战与证据链，固定数据集无法指明哪些要素可变换、哪些必须维持。
4. **技能与数据需联合驱动**：同一批执行轨迹既能揭示可复用工作流与失败模式（用于技能精炼），又能指明新数据应保留的核心挑战与可变维度，二者应共享信号而非独立优化。

## 核心贡献（创新点）
1. 提出技能-数据协同演化框架，通过执行轨迹共享证据实现双向闭环；区别于以往仅单点优化技能库或数据生成的独立自进化方法。
2. 设计基于更新收益归因的 UCB 种子选择与对比验证门控机制，将验证增益均摊至贡献实例并严格过滤无效更新；区别于依赖启发式采样或软性偏好反馈的技能/数据更新策略。
3. 构建分层技能库与靶向数据生成流水线，在固定模型参数下实现零样本跨域跨模型迁移；区别于依赖参数微调与同分布持续训练的传统 Agent 自我改进范式。

## 方法详解
- **问题设定**：固定参数多模态工具代理 $\pi_\theta$ 维护技能库 $S$ 与数据银行 $D$。联合优化目标为最大化技能更新奖励 $R(S';S)$ 与数据预期效用 $U(D';S)$，通过执行轨迹形成耦合循环（公式 1）。
- **技能演化**：
  - *轨迹分组与反思*：按路由到的具体技能或实例语义相似度（阈值 0.6）分组，对比成功/失败轨迹提取可复用工作流、缺失视觉证据、推理错误与适用条件偏差，生成技能补丁（编辑全局/具体技能或创建新技能）。
  - *对象级合并*：针对同一技能对象 $o$ 的补丁去重合并为候选更新 $\delta_o$，保留贡献实例集 $\mathcal{T}_o$。
  - *对比验证*：从独立验证池 $\mathcal{V}$ 检索对应面板 $\mathcal{V}_o$，在相同起点技能库 $S_{e,b}$ 上分别替换与不替换候选更新进行新鲜 rollout，计算奖励 $R_o = \frac{1}{|\mathcal{V}_o|} \sum_{d \in \mathcal{V}_o} [r(d; \tilde{S}_{e,b}^o) - r(d; S_{e,b})]$（公式 2）。仅接受 $R_o > 0$ 的更新并入库，同时刷新路由文档。
- **数据演化**：
  - *效用-探索选择*：将每次接受更新的奖励 $R_u$ 均摊给贡献实例，计算实例效用 $U_d = \sum_{u: d \in \mathcal{T}_u} R_u / |\mathcal{T}_u|$（公式 3）。结合累积效用 $A_d$ 与实践次数 $n_d$，采用 UCB 风格打分 $\sigma_d$ 排名选取生成种子（公式 4）。
  - *靶向生成与自检*：分析种子轨迹提取核心挑战、数据格式要求与可变维度，生成公开抽象计划。利用允许工具（图像生成/编辑、网页抓取、代码解释器等）构造新实例，通过四重自检（答案/证据可靠、图文一致、核心挑战保留、无泄漏捷径）后纳入 $D$。
  - *统计折扣与迭代*：新实例初始化 $A_d=n_d=0$，全量统计按折扣因子 $\gamma$ 衰减，为下一轮选取提供新鲜度激励。

## 实验与结果
- **数据集**：主评测 TIRBench、MMSearch-Plus、MMBrowseComp；转移评测 VisualToolBench、AgentVista。
- **基线**：Baseline (CoT)、Vanilla Tools、XSkill、Ace-Skill、SkillOPT（共享相同 rollout 训练预算）。
- **主要结果**：GPT-5.5 上 V-Gym 三项基准 Avg.@3 / Pass@3 全面领先，较最强基线分别提升 4.9/2.8、3.7/3.0、2.0/1.3 分（TIRBench 达 71.1/81.5）。Gemini-3.5-Flash 与 Qwen-3.7-Flash 上同样稳定超越 Vanilla Tools 及其他技能演化方法。
- **迁移效果**：跨域转移至 VisualToolBench 提升 Avg.@3 6.6 分、AgentVista 提升 4.1 分；跨模型转移至 GPT-5.4-mini 提升 6.7/5.6 分、Qwen-3.5-Flash 提升 4.1/2.3 分。
- **消融与持续演化**：移除对比验证门控导致 Avg.@3 下降最多（5.3 分）；共演化策略在 4 个 epoch 后 Avg.@3 比固定真实数据与通用合成数据分别高出 5.4 与 3.6 分，晚期技能更新接受率（25.6%）显著高于对比组（15.4% / 8.2%）。

## 相关工作脉络
1. **经验蒸馏与技能记忆**：XSkill、Ace-Skill、SkillOPT 等聚焦从轨迹提取程序技能，但多依赖固定数据集或单一策略优化，缺乏动态数据供给与收益归因机制。
2. **执行驱动的数据合成**：HardGen、VISA 等利用失败诊断或验证器反馈生成困难样本，但未将数据效用显式关联至技能更新收益，也未建立“数据反哺技能”的闭环。
3. **协同演化代理**：Skill Self-Play、SESA 等耦合技能生成与求解器训练，通常涉及策略更新或双生博弈；V-Gym 固定模型参数，仅通过技能库与数据集的双向迭代实现自提升。
