# 论文速读：Task-Oriented-Visual-Feature-Compression-via-Residual-Vector

## 一句话总结
本文提出查询引导的任务导向视觉特征压缩框架 Q-TOFC，通过将文本相关性融入 DPC-KNN 聚类选点与基于 RVQ 的离散编码相结合，在端边协同大模型推理中显著降低上行链路视觉负载，同时在多模态基准上保持与未压缩骨干相近的任务性能。

## 研究问题与动机
1. **端边协同的带宽瓶颈**：LMM 的视觉编码器输出稠密特征（如 SigLIP 单 patch 超 1.6 MiB），受限于无线上行链路带宽，直接传输导致严重延迟。
2. **现有特征压缩的查询盲区**：TOFC 等特征级方法采用无查询感知的 DPC-KNN 聚类合并 token，可能丢弃对用户文本指令关键的局部证据（如小物体、文字标识）。
3. **连续特征编码成本高**：TOFC 在聚类后仍对连续向量进行熵编码，单特征表示开销较大，限制了在极低 payload 下可传输的特征数量。
4. **图像级压缩的语义失配**：JPEG/ELIC 等以像素重建质量为目标优化，bit 分配策略面向人类视觉而非 LMM 下游推理，在低通信预算下表现劣于特征级方案。

## 核心贡献（创新点）
1. **查询引导的聚类中心选择机制**：在 DPC-KNN 密度-多样性得分中叠加文本-视觉余弦相似度加权，使合并后的特征自然偏向查询相关区域，与 TOFC 的无监督聚类形成本质区别。
2. **面向高维 latent 的 RVQ 编解码器**：将多层残差向量量化引入视觉特征压缩，以离散码本索引替代连续浮点传输，单特征开销从 16-bit×维度降至固定数十 bit，允许在同等预算下保留更多特征。
3. **任务驱动的量化误差补偿适配器（QECA）**：设计轻量级残差预测模块，在下一词预测损失与 VQ 特征正则化的联合监督下修正离散量化失真，避免纯 VQ 重建误差直接传导至 LLM。
4. **完整的端边延迟建模与系统性评估**：建立设备编码、上行传输、边缘推理三阶段延迟分解模型，并在七个多模态基准上验证 Q-TOFC 在通信-性能与端到端延迟上的综合优势。
