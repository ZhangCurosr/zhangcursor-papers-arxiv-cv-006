# 论文速读：TAEC-TRAJECTORY-AWARE-EVIDENCE-COORDINA-TION-FOR-MULTI-STEP

## 一句话总结
本文识别了多步视觉RAG中的"轨迹级证据利用退化"问题——即使检索到了相关证据，随着推理轨迹变长，这些证据也无法被有效使用。作者提出了TAEC（Trajectory-Aware Evidence Coordination），一种无需训练的协调层框架，通过共享的未解决问题状态来协调新证据准入、历史记忆呈现和视觉细节分配，在ViDoSeek、SlideVQA和MMLongBench-Doc上均取得了最佳性能。

## 研究问题与动机
- **核心问题**：多步视觉RAG系统在长推理轨迹上准确率显著下降。以ReAct在ViDoSeek上的实验为例，涉及多次搜索的轨迹中，检索到金色证据页（gold page）的问题准确率从2次搜索时的91.7%降至6-8次搜索时的63.8%，再到9次以上时的52.0%。
- **现有方法不足一**：检索相关性度量无法处理已检索信息冗余问题，多个高排名的候选源可能占用上下文空间却提供重复信息。
- **现有方法不足二**：累积的观察结果（observations）可能与已解决的子问题或未产出的搜索分支相关联，却仍残留在上下文中与后续推理所需信息竞争。
- **现有方法不足三**：保留的视觉源可能在模型当前信息需求下呈现的视觉细节不足，缺乏对"需要多少视觉精度"的动态评估机制。

## 核心贡献（创新点）
1. **首次系统性地识别并实证验证了"轨迹级证据利用退化"现象**：指出获取相关证据不等于有效利用证据，二者之间存在显著鸿沟——即便金色证据页已被检索入上下文，随着轨迹增长，其可用性持续下降。
2. **提出TAEC，一种基于共享未解决问题状态的训练自由协调框架**：通过Evidence Admission（证据准入）、Adaptive Memory Exposure（自适应记忆呈现）和Visual Detail Allocation（视觉细节分配）三个组件，围绕不断变化的推理需求协调输入、记忆和视觉资源的管理。
3. **在统一评估协议下实现了领先的零训练基线性能**：在ViDoSeek、SlideVQA和MMLongBench-Doc三个数据集上，TAEC在全部12个设置（4个VLM × 3个数据集）中均取得最高准确率，相对ViDoRAG分别提升7.8、11.1和18.6个百分点。
4. **提供了多维度的机制可解释性分析**：包括轨迹深度分解、覆盖-使用分解、上下文组成分析和效率分析，揭示了协调机制在不同推理阶段的贡献模式。

## 方法详解
**总体框架**：TAEC构建在轨迹图$G_t$之上，每个节点代表一次搜索及其关联的观察结果。维护一个共享的需求状态$\mathcal{U}_t=\{(\bar{u},\bar{w}_{u,t})\}$，跟踪未解决的回答需求及其当前支持程度。

**组件一：Evidence Admission（证据准入）**
- 目标函数（公式2）：最大化未解决问题覆盖率、检索相关性之和，同时惩罚候选源之间的冗余度。
- 实现：对25个过采样候选（5×5）进行贪心选择，始终以检索器Top-1为锚点保留最强信号，其余按边际增益填充。冗余度用Jaccard相似度衡量，覆盖度用slot关键词子串匹配估计。

**组件二：Adaptive Memory Exposure（自适应记忆呈现）**
- 记忆持久性（公式3第一项）：采用粒度依赖的指数衰减$e^{-\lambda_{g_m}\Delta t_m}$，不同信息粒度（page/region/entity）对应不同衰减率。
- 观察渲染策略（公式3第二项）：根据当前轨迹角色$s_{m,t}$决定呈现形式——活跃/不确定观察完整呈现，已解决观察压缩为简洁事实陈述，失败分支表示为简短终止痕迹。

**组件三：Visual Detail Allocation（视觉细节分配）**
- 公式（4）：将视觉预算$B_t$按比例分配给保留的历史图像，第一项保持后端相关性权重，第二项使用softmax调度，综合考虑图像相关性$r_{i,t}$、估计细节收益$d_{i,t}$和需求支持$c_{i,t}$。
- 视觉预算$B_t$随上下文压力动态调整，而非固定值。

**需求状态提取**：每个问题通过一次GPT-4.1-mini调用（temperature=0）提取2-4个信息槽关键词，缓存后截断至4个槽，权重均匀分配。

## 实验与结果
**数据集**：
- **ViDoSeek**：1,142个问题，290个PDF文档渲染为页面图像，每问题标注1个金色证据页；645单跳，497多跳。
- **SlideVQA**：2,215个问题，基于幻灯片。
- **MMLongBench-Doc**：847个标注为可回答的问题（共1,091题中244题为不可回答）。

**评估设置**：
- 四个闭源VLM：Gemini-3.5-Flash、Kimi-K3、GPT-5.6-Sol、GPT-4o-mini。
- 统一协议：相同只读检索索引（Qwen3-VL-Embedding-2B FAISS索引，36,233页）、相同每轮 admitted 页面数（≤5）、相同交互预算（≤20次调用）、相同judge（GPT-4.1二元判断）。
- 所有模型保持冻结，TAEC无训练。

**主要结果（Table 1）**：
| 数据集 | TAEC (Gemini) | 最优基线 | 提升 |
|---|---|---|---|
| ViDoSeek | **87.5%** | ViDoRAG 79.7% | **+7.8pp** |
| SlideVQA | **83.6%** | ReAct 82.0% | **+1.6pp** |
| MMLongBench-Doc | **50.1%** | ReAct 42.4% | **+7.7pp** |
| **Avg (12 settings)** | **66.8%** | DAG agent 62.3% | **+4.5pp** |

**关键发现**：
- TAEC在12个设置中10个领先，仅MMLongBench-Doc上GPT-5.6-Sol和GPT-4o-mini稍逊（因不可回答问题判定能力差异）。
- 相对M3RAG（重新实现）提升5.0、2.1、2.5pp。
- 轨迹深度分析：在≥4次搜索的问题组中，TAEC相对ReAct分别提升28.1pp（ViDoSeek）、26.6pp（SlideVQA）、13.6pp（MMLongBench-Doc）。
- 组件消融：三组件各自贡献约41%-88%的总增益，准入组件在ViDoSeek和MMLongBench-Doc上贡献最大（分别为6.2/7.4pp和3.7/5.6pp）。
- 效率优势：TAEC平均每问题传输0.61MB上下文（vs ReAct的3.73MB）、14.7张图像（vs ReAct的92.8张）。

## 相关工作脉络
1. **ViDoRAG (Wang et al., 2025a)**：多智能体视觉RAG框架，公开代码；TAEC在相同协议下超越它，且TAEC为训练自由、单模型架构，无需多智能体编排。
2. **ReAct (Yao et al., 2023)**：经典think-search-observe循环，保留所有检索图像；本文揭示其长轨迹退化问题，TAEC在其基础上引入需求感知协调。
3. **M3RAG (Du & Li, 2026)**：多智能体推理架构，代码未公开，本文重新实现对比；TAEC作为训练自由方案在多数设置下优于它。
4. **Self-RAG / FLARE / DeepRAG / CRAG**：自适应检索方法，通过置信度/反思/质量评估指导检索决策；TAEC与它们正交——不改变检索策略，而是管理已检索证据的使用。
5. **VISOR (Shen et al., 2026) / VimRAG (Wang et al., 2026a) / MAGE-RAG (Zuo et al., 2026)**：近期 agentic 视觉RAG系统，分别通过结构化证据空间/语义优先级图/查询特定子图管理上下文；TAEC聚焦于"证据准入-记忆呈现-视觉分配"三个决策的统一协调。
6. **VRAG-RL (Wang et al., 2025b)**：通过强化学习训练检索和视觉感知策略；TAEC与RL方法正交——TAEC固定策略并改进证据呈现，两者可组合。

## 局限性与未来方向
- **依赖 acting model 的 agent 能力**：TAEC不能弥补模型自身推理轨迹控制能力的缺陷；与Qwen2.5-VL-7B的实验显示，当模型频繁在无搜索情况下作答（24.2%）或过度搜索时，TAEC增益有限甚至为负。
- **主要比较限于单一检索器族**：正文仅使用一个密集检索器，替代检索器的实验仅见于附录。
- **数据集语言限制**：三个基准均为英文文档集合，泛化到多语言场景尚待验证。
- **未解决"不可回答"问题判定**：MMLongBench-Doc中244道不可回答问题，TAEC的三个组件均未针对此类判定进行优化。
- **未来方向**：与策略训练（policy training/RL）结合、扩展到开放权重模型、支持多语言文档集合。

## 研究启发与可借鉴点
1. **需求感知协调的原则可迁移**：将"追踪未解决问题状态→据此管理资源分配"的思路，可推广到文本RAG、代码RAG、多模态agent等其他需要多步证据管理的场景。
2. **轨迹图建模的价值**：以DAG表示搜索间的依赖关系，将观察结果与产生它的搜索节点绑定，为后续的需求覆盖分析提供了结构基础；这一建模方式值得在其他多步推理系统中借鉴。
3. **粒度依赖的记忆衰减机制**：区分page/region/entity不同粒度的信息价值，采用差异化衰减率，比全局统一衰减更合理；类似思想可用于长上下文压缩。
4. **实验设计的严谨性**：统一协议（共同检索索引、共同judge、共同budget）+ 行为指纹验证 + 四组分解放置（coverage/use decomposition），确保了结论的可信度，是RAG评估的标杆做法。
5. **与RL方法的正交性启示**：TAEC与VRAG-RL等作用不同层面，组合潜力已被验证（+0.7pp）；这提示我们可以在策略训练之外，额外投资"证据呈现协调"这一低成本高回报的优化维度。

## 关键术语表
- **Trajectory-level evidence utilization degradation**：轨迹级证据利用退化——指在多步视觉RAG推理过程中，即使检索到了相关证据，随着轨迹增长，这些证据的有效利用率持续下降的现象。
- **Requirement state ($\mathcal{U}_t$)**：需求状态——追踪未解决回答需求的紧凑集合，每个需求包含需求内容和当前支持权重，是TAEC三个组件的统一决策基础。
- **Evidence Admission**：证据准入——基于增量贡献（覆盖未解决问题程度）和冗余度，从过采样候选中贪心选择进入上下文的证据。
- **Adaptive Memory Exposure**：自适应记忆呈现——根据记忆项在轨迹中的角色（活跃/已解决/失败分支），动态调整其呈现粒度（完整/压缩/终止痕迹）和持久性（粒度依赖衰减）。
- **Visual Detail Allocation**：视觉细节分配——根据图像相关性、估计细节收益和需求支持度，动态分配视觉处理预算（像素数），而非均匀分配。
- **Gold page**：金色证据页——标注的正确答案来源页面，用于衡量检索覆盖率和证据可用性。
- **Coverage vs Use decomposition**：覆盖-使用分解——将准确率增益拆分为"仅TAEC检索到金色证据"和"两者均检索到但TAEC使用更好"等分组，量化各机制的贡献来源。
